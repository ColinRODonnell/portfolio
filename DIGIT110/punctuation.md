# Punctuation I Use as a DIGIT Student

DIGIT students come across different types of punctuation when coding.

These are the most popular ones that I encounter when I code for DIGIT:

<ol>
<li>. (period)</li>
Mostly used for file extensions, .py .xml .md. Can be part of commands in the shell
<li>/ (foward slash)</li>
The foward slash is used for file directories c/github/portfolio and also URLs.
<li>- (hyphen)</li>
Used for command line in the GitBash Shell. git commit -m.
<li>" (quotation marks)</li>
Quotation marks are used for attributes. Style:color="blue".
<li>:, ; (colon & semicolon)</li>
The colon and semicolon are very commonly used in CSS and website making. font-size:16px;

--

These are the most common punctuation that I use in coding.
